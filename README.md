# Calculadora de notas

Proyecto de ejemplo para la tarea 1 del curso de programación (repositorio ficticio de demostración).

La calculadora lee las notas de un curso desde un archivo CSV y entrega el promedio ponderado.

## Cómo usarla

```bash
python main.py datos/ejemplo.csv
```

El archivo CSV tiene tres columnas: `evaluacion`, `nota` y `ponderacion` (en porcentaje).
